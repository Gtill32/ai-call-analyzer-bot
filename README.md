# 🤖 AI Call Analyzer Bot

Telegram-бот для автоматического анализа телефонных звонков с помощью AI. Загружаете аудиозапись разговора — бот делает транскрибацию и выдаёт структурированный отчёт, адаптированный под конкретный бизнес-сценарий.

## 🎯 Задача

Ручной анализ звонков — долгий и субъективный процесс. Бот автоматизирует эту задачу: распознаёт речь, определяет участников разговора, выявляет проблемы клиента, оценивает качество работы оператора/менеджера и настроение клиента по ходу звонка.

## ⚙️ Как это работает

```
Аудио/голосовое сообщение
        ↓
  Whisper (транскрибация речи в текст)
        ↓
  LLM-анализ по выбранному сценарию
        ↓
  Структурированный отчёт пользователю
```

1. Пользователь выбирает тип звонка через inline-кнопки: **Продажи / B2B**, **Поддержка**, **Конфликт / Фрод**
2. Отправляет аудиофайл или голосовое сообщение
3. Бот транскрибирует речь (Whisper large-v3)
4. Транскрипция передаётся в LLM вместе с системным промптом, заточенным под выбранный сценарий
5. Результат форматируется и отправляется пользователю
6. Есть дополнительная функция — разбивка транскрипции по ролям (кто что говорил)

## 🛠 Стек технологий

- **Python** — основной язык
- **python-telegram-bot** — асинхронная работа с Telegram Bot API
- **Groq API** — провайдер AI-моделей:
  - **Whisper large-v3** — транскрибация аудио в текст
  - **Llama 3.3 70B** — анализ транскрипции и генерация отчёта

## 🧠 Особенность реализации — разные промпты под разные задачи

Под каждый бизнес-сценарий (продажи, поддержка, конфликт) используется свой системный промпт с уникальным набором критериев оценки — например, для продаж это «вероятность сделки» и «работа с возражениями», а для поддержки — «решена ли проблема» и «вежливость оператора».

## 🔒 О версии в этом репозитории

Это демонстрационная версия проекта для портфолио. Реальные API-ключи и бизнес-специфичные данные клиента удалены. Код показывает архитектуру и подход к решению задачи.
